# Pencil2 with native-constructed AGLL owner

After v219 preparation, run `python3 tools/pencil2-worker-v282/probe.py` and `PENCIL_SKIP_DRAW=1 python3 tools/pencil2-worker-v282/probe.py`. This extends v281 by calling the native `AGLLThreadGLImpl` constructor on the host-allocated owner. It initializes two queue sentinels and places an initialization task on the first queue. Native `RunTasks` drains that task with its Run skipped and its slot 8 observed, returning the first queue to the empty sentinel. Native enqueue then places the captured Pencil2 task on that constructed owner; native drain invokes its Run and slot 8 exactly once. The original manager canvas, attachment, drawable, matrix and v281 draw and skip frame hashes are asserted.

The constructor executes under single-threaded emulation with a host compare-and-swap adapter for an unsupported ARM instruction. Queue locking, logging and pointer exchange remain stubbed; the initial task Run is skipped and the captured Pencil2 message is inserted by the host after interception. Slot 8 execution alone does not establish destruction or resource lifetime. Canvas injection, readback framebuffer binding, actual producer scheduling, threading, saved-page traversal and device behavior remain outside this control. Host Mesa and transitive dependencies are not fully pinned. The frame is the prior v274 export-comparison fixture; no new SVG or PDF comparison is claimed.
