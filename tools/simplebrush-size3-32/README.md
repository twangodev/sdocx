# SimpleBrush tool 0, size 3

Synthetic 16, 32 and 64-point ObjectStroke controls run Drawing with a 2× matrix and fractional translation, host-scheduled tasks and an explicit target preclear, using the pinned capture dependencies checked by `capture.py` against `conformance/simplebrush-scale-2x-host.json`. The local capture wrapper adds the 16-point case; the retained receipts include geometry, GL verdicts, frame and public export hashes. Compressed RGBA frames are retained here. This is not native page traversal or device/saved-note parity. The three cases bound the new 16–64 point size-3 admission; arbitrary paths and point counts between controls are not exhaustively verified.

From the repository root, create `/tmp/simplebrush-size3-N` and run `SDOCX_ROOT="$PWD" POINT_COUNT=N PROBE_SIZE=3 python3 tools/simplebrush-size3-32/capture.py fraction12 /tmp/simplebrush-size3-N/native.json --tool 0` for N=16, 32, 64. Run `two_pixel_native_export_fixture` with `SDOCX_POINTS_COUNT=N PROBE_SIZE=3 SDOCX_TOOL=0 SDOCX_V62_NATIVE=/tmp/simplebrush-size3-N/native.json SDOCX_SIMPLEBRUSH_TWO_EXPORT=/tmp/simplebrush-size3-N`, the project Cargo settings, and features `pdf,serde`. Then run `tools/simplebrush-size3-32/compare.py` and `tools/simplebrush-size3-32/pdfium.py` on the output directory with the reader versions documented by those scripts. MuPDF uses the fractional transform; the PDFium comparison is unshifted and therefore is a separate approximate control. Temporary public exports are hashed in the receipts.

`check_exports.py` is an automated endpoint regression: it verifies the retained native frame hashes, generates fresh actual public SVG and direct PDF exports, verifies geometry, and asserts improvement against generic output using resvg, MuPDF, and PDFium. Run it with the pinned readers, for example `PYTHONPATH=/home/jding/.cache/uv/archive-v0/m2iYXlbbXfH_7VNskMx4c .venv/bin/python tools/simplebrush-size3-32/check_exports.py`. The comparator removes the SVG paper background and uses the captured fractional 2× transform; MuPDF compares RGB over rendered paper at the same phase. PDFium uses the existing unshifted control. Thresholds check substantial improvement rather than exact pixel equality. The receipts pin the capture wrapper, primary native library, original scripts, comparator and reader versions; scratch helper and transitive dependencies are not fully pinned, and the original exports came from a dirty source tree. Their hashes do not establish complete source-to-binary identity.
