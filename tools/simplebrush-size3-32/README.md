# SimpleBrush tool 0, size 3

The experimental public-export generator, comparators and replay callers have been retired. Export hashes and external SVG/PDF reader measurements below are historical observations, not current reproduction instructions or full source/build attestations. Native capture commands, inputs and receipts remain retained.

Synthetic 16, 32 and 64-point ObjectStroke controls run Drawing with a 2× matrix and fractional translation, host-scheduled tasks and an explicit target preclear, using the pinned capture dependencies checked by `capture.py` against `conformance/simplebrush-scale-2x-host.json`. The local capture wrapper adds the 16-point case; the retained receipts include geometry, GL verdicts, frame and public export hashes. Compressed RGBA frames are retained here. This is not native page traversal or device/saved-note parity. The three cases bound the new 16–64 point size-3 admission; arbitrary paths and point counts between controls are not exhaustively verified.

From the repository root, create `/tmp/simplebrush-size3-N` and run `SDOCX_ROOT="$PWD" POINT_COUNT=N PROBE_SIZE=3 python3 tools/simplebrush-size3-32/capture.py fraction12 /tmp/simplebrush-size3-N/native.json --tool 0` for N=16, 32, 64. MuPDF uses the fractional transform; the PDFium comparison is unshifted and therefore is a separate approximate control. Temporary public exports are hashed in the receipts. The historical comparator removed the SVG paper background and uses the captured fractional 2× transform; MuPDF compares RGB over rendered paper at the same phase. PDFium uses the existing unshifted control. Thresholds check substantial improvement rather than exact pixel equality. The receipts pin the capture wrapper, primary native library, original scripts, comparator and reader versions; scratch helper and transitive dependencies are not fully pinned, and the original exports came from a dirty source tree. Their hashes do not establish complete source-to-binary identity.

The Rust `tool0_size3_endpoint_native_geometry` regression checks the retained 16/64-point geometry and native frame hashes, exact nonempty SVG support, and alpha error below 10% of generic rendering in memory. It does not revalidate the historical external PDF reader measurements.
