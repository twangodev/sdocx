# Investigative 25-point Montblanc control

One synthetic size-1, constant-pressure 25-point path extends the existing 24-point boundary. `setup-experiment.py` retains its exact input and constructs an isolated `/tmp/sdocx-mb25-run` candidate by widening only the sampler and `prepare` bounds to 25; it also appends a test comparing every callback lane bitwise against the native stream. The native capture and complete stderr callback stream are compressed here. The adapter supplies points and pressures without independently reading them back. This is Drawing/host-Mesa evidence, not saved-note, device, lifecycle, or native-PDF parity. The original render.rs was dirty; the source hashes below pin selected files only, not a complete build closure.
