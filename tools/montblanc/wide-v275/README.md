# Montblanc size 2.4 diagnostic

A synthetic ten-point zigzag with varied pressures was captured through native Drawing and host Mesa. The complete 53-record callback stream matches the Rust sampler when its size guard is removed. The original stream and input are in `native.json`; `capture-1.json` and `capture-2.json` retain the compressed frames and metadata needed by the reader comparison. These controls do not establish saved-note, device, or arbitrary-path behavior. Capture dependencies and native library pins are recorded in the frames; the full host dependency closure is not pinned.

The isolated `width.patch` changes the size dispatch and sampler guard only; it is a diagnostic, not a proposed production admission. The sampler guard is removed entirely in this patch, so it is not safe for production callers. On the 1× frame the candidate reduced union RGB L1 error versus fallback in SVG/resvg (91,021 to 15,116), direct PDF/MuPDF (88,149 to 11,442), and direct PDF/PDFium (82,574 to 11,053). It overcovered the native SVG support (370 versus 329 pixels), and generated 660,975-byte SVG and 219,774-byte PDF versus 1,206 and 1,889 bytes for fallback. At 2× the candidate and fallback files are byte-identical: another admission condition selects fallback. This supplies no 2× candidate evidence. Only one trajectory was compared; no production change follows.

The Rust `wide_size_diagnostic_retained_receipts` test checks retained frame hashes, stream count, input, reader inequalities, and the byte-identical 2× outputs. It checks recorded results, not fresh rendering or native recapture. The export receipt pins the clean source revision `f7666dd0004173f49c93e7e5115c358dfe52cff2` through its selected source hashes, plus reader versions, raster and document hashes; it does not pin the complete dependency closure.

To replay against a clean Git archive and rerender both public outputs, install resvg, PyMuPDF, Pillow and pypdfium2 with the reader versions recorded in `export-receipt.json`, then run `PYTHON=.venv/bin/python python3 tools/montblanc/wide-v275/replay.py` with the shared Cargo target available. The script applies the diagnostic patch to a temporary archive, checks all callback methods and float words, builds clean baseline and candidate exporters, and compares document and raster hashes and reader metrics with the retained receipt. The generated driver source hash depends on the temporary archive path and is excluded from receipt equality; its source is generated from the pinned driver and retained input. It removes its temporary workspace. Replay reconstructs both callback stream sidecars from `native.json`; comparing those sidecars does not independently verify either frame capture's original stream. The native frame is retained evidence; this replay does not recapture native output.
