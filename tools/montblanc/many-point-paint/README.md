# Six- and seven-point Montblanc paint controls

From the repository root, run `.venv/bin/python tools/montblanc/many-point-paint/verify.py`. This archives the pinned committed source revision and checks its source hashes before building public 1× and 2× SVG/PDF exports, executes the native Drawing/host-Mesa captures, checks callback streams, library pins, matrix and frame/vertex hashes, and compares rasterized output with the compact receipt. It requires the pinned native libraries in `scratch/apk-analysis-native/arm64-v8a`, runtime adapters, Unicorn, EGL/GLES, resvg, Pillow and PyMuPDF. It uses the shared agent Cargo target and deletes transient output.

Support counts are pixels differing from #fcfcfc by more than 2 RGB levels; RGB error is the sum of absolute byte differences over the union. Both formats improve on these four synthetic controls at each scale, but overcover native support and produce much larger output. Geometry and paint beyond these controls, actual saved notes and device output are unverified.
