# Montblanc circular cutoff clipping experiment

This isolated experiment clips each subdivided patch in interpolated UV coordinates to an inscribed regular 32-gon approximating the shader's radius-0.5 cutoff, triangulates the result, and samples alpha at each resulting triangle's centroid. It does not round output coordinates. This is an approximation: the shader's smooth transition and framebuffer antialiasing remain distinct from geometric clipping. The patch is experimental, including its existing patch-budget accounting, and is not suitable for production without addressing increased path count and resource limits.

Against retained independent Drawing/host-Mesa frames, support was defined by RGB difference greater than 2 from #fcfcfc. The unit suite has 12 controls: four 21–24-point paths at sizes 0.5, 1 and 2. The 2× suite has four 12–20-point paths at size 1.5. Across each suite, clipping reduced output support on every control in all three readers. Ratios below compare union RGB L1 error to the unclipped production approximation; smaller is better.

| Suite | resvg SVG error ratio; improved cases | MuPDF direct PDF | PDFium direct PDF | SVG size ratio | PDF size ratio |
| --- | --- | --- | --- | --- | --- |
| 1× | 0.990–1.009; 6/12 | 0.948–0.964; 12/12 | 0.929–0.962; 12/12 | 1.70 | 1.76–1.85 |
| 2× | 0.882–0.903; 4/4 | 0.815–0.868; 4/4 | 0.806–0.865; 4/4 | 1.70 | 2.19–2.43 |

The complete compact receipts retain per-control metrics, output hashes and reader versions. The frame captures and input streams are in the existing `long-unit-size-v205` and `long-2x-independent` directories. These are synthetic captures; their adapter does not independently read back supplied inputs. They do not establish device, saved-note, lifecycle, arbitrary-transform or native-PDF parity. The 25-point exploratory result previously reported used coordinate rounding as well and is not a clipping-only measurement.
