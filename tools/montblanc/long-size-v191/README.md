# Longer unit-scale size controls

Four independent synthetic Drawing/host-Mesa shapes use 12 or 20 points, each at sizes 0.5, 1 and 2. `streams.json` retains every captured callback and float lane; the Rust long-stream test matches all 12. `native.tar.gz` retains the native frames and streams, and `receipt.json` records paired public SVG and direct PDF outputs, hashes and reader metrics. On all 12 cases, candidate union RGB error is 13.0–15.4% of fallback with resvg, 9.9–12.5% with MuPDF, and 10.3–12.4% with PDFium. Candidate SVG files are 573–643 KB and PDFs 148–179 KB. These synthetic measurements do not establish saved-note, native PDF, lifecycle or device parity. They do not establish behavior at other scales or sizes below 0.5.

The receipt pins selected source files, the comparison script, public export harness and manifest. The paired builds use isolated copies with the old and expanded gates and the shared Cargo target. The selected pins do not cover every transitive dependency. To recapture, choose a fresh temporary directory for `MB_EXPORT_WORK` and run `compare.py capture`; then run `compare.py compare` with the same directory. The capture requires the pinned runtime documented in `../many-point-paint/README.md`, and comparison requires resvg, Pillow, MuPDF and PDFium. The new receipt is created exclusively inside the work directory by default. To check retained exports against the receipt, run `compare.py verify` with the same work directory. Rebuilding from the retained native archive requires extracting it into one fresh capture directory and setting `MB_CAPTURE_WORK` to that directory and `MB_EXPORT_WORK` to a second fresh directory before running `compare.py rebuild-verify`.
