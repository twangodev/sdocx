# Longer unit-scale Montblanc controls

Six synthetic native Drawing/host Mesa inputs have 12, 14, 17, or 20 points at pen size 1.5. They include turns, loops, reversals, varying pressures and rejected short moves; the 12- and 20-point holdouts are distinct from the first four. Rust replay matches every captured callback and float lane. The public 1× SVG and direct PDF candidate reduces RGB absolute error against the native frame for every case in resvg, MuPDF and PDFium, while overcovering native support. This is not saved-note, native PDF, lifecycle or device parity. The 20-point SVG grows to roughly 1 MB; the existing 256-record and page patch budgets remain in force.

`native.tar.gz` retains the synthetic captures and streams; `streams.json` holds the callback test inputs. For fresh capture, run `compare.py capture` with `MB_EXPORT_WORK` set to a new empty directory. For verification, use that capture directory as `MB_CAPTURE_WORK` and a second new empty directory as `MB_EXPORT_WORK`, then run `compare.py rebuild-verify`. The runtime dependencies and partial native pinning match `../long-paint/README.md`; the interpreter also requires pypdfium2. Use only fresh directories: the script creates files within them. The receipt records renderer versions, hashes, and RGB/support metrics. Temporary exports are reproducible and need not be retained.
