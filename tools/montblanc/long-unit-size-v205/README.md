# Montblanc long unit-scale size controls

Twelve fresh synthetic Drawing/host-Mesa captures exercise 21–24 points at sizes 0.5, 1 and 2. The 21-point hook and 24-point zigzag reuse prior trajectories with new sizes; the 22-point skipped-move and 23-point loop paths are independent holdouts. The capture adapter supplies points and pressures without independently reading them back. The durable Rust test checks every captured callback lane bitwise.

The unit profile admits 21–24 points at sizes 0.5–2. All twelve candidates reduce union RGB absolute error versus generic fallback in SVG/resvg and direct PDF/MuPDF and PDFium, while overcovering native support. The captured SVGs are approximately 0.9–1.1 MB per stroke. The comparator's artifact-size assertions are post-output checks, not runtime limits. Intermediate sizes and arbitrary trajectories are extrapolations; saved-note, device, native-PDF and lifecycle parity remain unverified. The 2× admission remains limited to 20 points.

Unpack `native.tar.gz` into a fresh directory, set `MB_CAPTURE_WORK` to it and `MB_EXPORT_WORK` to a different fresh empty directory outside the repository, then run `PYTHONPATH=/tmp/marker2-pdfium-python .venv/bin/python tools/montblanc/long-unit-size-v205/compare.py rebuild-verify`. The comparator verifies captured stream and frame hashes, selected source pins, output hashes, reader versions and metrics. The pins are partial and do not establish a complete build closure. Use `capture` with a fresh empty output directory to acquire new native controls. Temporary outputs are reproducible intermediates.
