# SimpleBrush size-three 128-point controls

Two synthetic tool-0 size-3 captures use a fractional 2× host transform. The baseline fits within the capture; the alternate crosses the right edge and is clipped. Both native geometry streams match Rust byte for byte. The host GL paint verdict is clean. The candidate reduces SVG alpha and direct-PDF RGB errors against generic output in resvg, MuPDF, and PDFium; exact values, output sizes and hashes are in `receipt.json`. Candidate files are approximately 170 KB SVG and 830 KB PDF, versus 15 KB and 2.6 KB generic. This is a size tradeoff bounded by the existing shared sample budget. Intermediate point counts extrapolate from these captures; they do not establish saved-page or device parity.

`capture.py` reproduces native capture using the receipt-pinned project-local scratch inputs (transitive native runtime dependencies are not fully pinned): `POINT_COUNT=128 PROBE_SIZE=3 python3 tools/simplebrush-size3-128/capture.py fraction12 /tmp/NEW/native.json --tool 0`; set `VARIANT=alternate` for the clipped control. Create `/tmp/NEW` first. Compact native JSON retains the vector, readback metadata and GL verdict; compressed frame files retain the readback. Full original native JSON hashes are in the receipt.

`verify.py` archives the pinned clean source revision, applies the candidate and comparison-fixture patches, rebuilds the public exports, compares geometry and export hashes, and checks the reader metrics. It replays retained native data and requires the exact recorded versions: resvg 0.45.1, PyMuPDF 1.28.2, pypdfium2 5.9.0 with PDFium 150.0.7869.0, Pillow 12.1.1, and NumPy 2.4.2. The verifier checks these versions and runs Cargo with `--locked --offline`; the locked dependencies must already be cached. This proves the paired controls, not native recapture or all supported inputs.
