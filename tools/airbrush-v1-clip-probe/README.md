# AirBrush V1 triangle clip experiment

This isolated experiment replaces the three gradient masks on each image triangle with a geometric SVG clip path. It keeps the per-triangle texture transforms. The retained synthetic Model/Drawing host-Mesa frames and stamp streams are the targets; these are not device or saved-note evidence. This change is rejected: it degrades all three resvg frames and most PDF metrics. The source patch also affects V2; the existing `saved_v2_tool1_native_motion_exports` test fails its native-frame hash. The scale2 patch has the incidental V2 tool-sampling change described in the scale2 README, so the V2 failure is evidence of a regression in the combined experiment, not isolation of its cause.

Against native, in order resvg premultiplied RGBA, MuPDF premultiplied RGBA, PDFium alpha and white RGB absolute errors: zigzag 541, 7393, 2490, 4305 (baseline 0, 6952, 2329, 4063); reverse 259, 2429, 826, 1325 (baseline 0, 2216, 818, 1325); scaled reverse 579, 6166, 2241, 3543 (baseline 0, 5421, 2216, 3646). Baselines are from the tool1 and scale2 receipts. Geometry bytes match native on all three controls. The frame and vector inputs are retained in those receipts.

To replay, run these commands from the original workspace with `/tmp/airclip-replay` and `/tmp/airclip-pdfs` absent. The tests also write `/tmp/airclip-{zigzag,reverse}-{candidate,generic}.{svg,png}` and `/tmp/airbrush2x-*`; preserve existing files at those paths first. The test filter runs unrelated tool1 tests; the V2 failure above is expected.

```sh
mkdir /tmp/airclip-replay /tmp/airclip-pdfs
git archive 417cab5c | tar -x -C /tmp/airclip-replay
git -C /tmp/airclip-replay apply "$PWD/tools/airbrush-v1-clip-probe/scale2.patch"
git -C /tmp/airclip-replay apply "$PWD/tools/airbrush-v1-clip-probe/clip.patch"
(cd /tmp/airclip-replay && CARGO_TARGET_DIR=/tmp/sdocx-agent-target CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 CARGO_BUILD_JOBS=2 SDOCX_AIRBRUSH_MATRIX_DIR=/tmp/airclip-pdfs cargo test -p sdocx --lib --features pdf tool1_ -- --nocapture)
PYTHONPATH=/tmp/pdfium-lib .venv/bin/python tools/airbrush-v1-clip-probe/compare.py
```

Run the comparison from this checkout, using PyMuPDF 1.28.2, Pillow 12.1.1 and PDFium 150.0.7869.0. The retained native inputs are `tools/pen-capture/airbrush_v1_tool1_receipt.json` (SHA-256 `4802a26da96ddf3e2f9a6656aff5becae7dea7ab8ac19bfdc03585dbd308699b`) and `tools/airbrush-v1-tool1-scale2/receipt.json` (SHA-256 `dc7adeedcd4ab73070e7048189b4af01456eec4e8ff881811876b91bc347869c`). SVG PNGs are generated by resvg in the Rust tests, and PDF files are direct scene exports. The comparison asserts the full scaled vector and all measured errors, input frame hashes, receipt hashes, and renderer versions. The comparison samples at 96 dpi; other scales and ordered scenes remain untested.
