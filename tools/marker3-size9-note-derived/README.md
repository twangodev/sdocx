# Marker3 size-9 note-derived counterexample

This control starts with stored stroke 29 from `tmp/stroke-conformance/handwritten.sdocx` (document SHA-256 `77e3997a066afa0333d0f5020bb428efffeb783c741bc956ae596292e2d5cda3`), as recorded by `conformance/fountain-v14-saved-scene-inputs.json`. Its decoded `crates/sdocx/tests/assets/fountain-v14/saved-source-29.json` has SHA-256 `022d75f1dcfe52bb669280062cf95ac77e3818354d1cbb6edb5cb7265898e9dd`. This was a FountainPen source, not a saved Marker3. The 57 positions were translated by (-96,-268); pressures, timestamps, tilt and orientation were preserved. Marker3 V5, tool 1, size 9, ARGB `0x80336699` and `5;` replace the original pen metadata. Both native and public-export controls use these inputs, with native Model f32 conversion. See the compact fixture for exact native setter arrays and vectors.

The fresh native Model/Drawing captures use the same explicit RT vector bridge and host Mesa boundary as `../marker3-size9-diverse`. Each scale emits the same 10-point Drawing and saved-redraw vectors. The prior Rust sampler emitted 7; the corrected sampler matches all 10 positions bit for bit in both native phases. Instrumented capture checks each `drawPoint` input against the final native vector. ObjectStroke `RedrawPen` loads `GetInitialToloerance()` into drawable offset 44 (native Marker3 offsets `0x3e370`–`0x3e378`); Model getter `0x2e24a0` reads object offset 356. With no setter invoked on this host-created Model object, the observed value is zero. The previously assumed value 2 was the drawable constructor default. The original serialized note's tolerance is not established by this control. The retained frame hashes, driver and traced input coordinates are in `native-receipt.json`. This neither establishes serialized Marker3 note parity nor the original device rendering or lifecycle. Transparent frames and mathematical composition over #fcfcfc are tested; native opaque backgrounds and reuse/lifecycle are not tested.

`comparison.json` records full-frame absolute channel errors for the size-9 admission at commit `9b5346be` against native, alongside generic fallback. Default and explicit profiles improve SVG, MuPDF and PDFium error at all three scales. Both admitted SVG variants miss six native support pixels at 4x, and none at 1x or 2x. The generic fallback misses 139, 584 and 2366 respectively. These measurements precede the geometry correction. `candidate-comparison.json` records the corrected sampler: neither admitted variant misses support at any scale, though default aggregate error rises slightly and the explicit 1x PDFium error also rises. Every candidate mode remains below generic aggregate error. Neither aggregate improvement nor matching geometry establishes pixel parity.

On a prepared host, `.venv/bin/python tools/marker3-size9-note-derived/capture.py /tmp/marker3-note` repeats the host capture. It requires the incomplete, locally held proprietary binaries and helper closure described in `../marker3-terminal/README.md`; it is not a self-contained native capture recipe. `PYTHON=.venv/bin/python PYTHONPATH=/tmp/sdocx-marker3-v133-readers bash tools/marker3-size9-note-derived/replay.sh` rebuilds public SVG/direct PDF outputs from archived `9b5346be`, the archived generic gate, and the current candidate sampler copied into that archive, then checks both retained comparisons against the native frames. It requires the local Cargo cache, shared target, `resvg`, MuPDF and PDFium versions checked by the comparator. It links workspace conformance and tools to compile, and does not pin their complete dependency closure. The prior generic gate is built in a temporary archive, and all output intermediates are removed on exit.

`PYTHON=.venv/bin/python PYTHONPATH=/tmp/sdocx-marker3-v133-readers bash tools/marker3-size9-note-derived/replay-diverse.sh` also builds the current sampler into the original diverse-control archive and checks all nine reader comparisons against the original receipt. The corrected candidate reproduced every prior metric, including zero missed SVG support pixels. Like the other replay, this checks a bounded local archive and reader setup rather than pinning a complete build closure.
