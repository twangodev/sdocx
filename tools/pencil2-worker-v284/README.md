# Pencil2 native constructor task

After the v219 preparation, run `python3 tools/pencil2-worker-v284/probe.py` and `PENCIL_SKIP_DRAW=1 python3 tools/pencil2-worker-v284/probe.py`. This extends v283 by executing the constructor's queued task Run before producer submission. Its dispatch, return from Run, slot-8 entry, and return from slot 8 are asserted, followed by an empty queue. The five subsequent native producer submissions drain in FIFO order. Both controls retain the v283 canvas, matrix, framebuffer and output assertions: draw changes 322 bytes; skip changes none.

Executing the task requires bounded host adapters for `strtof` and `posix_memalign`. The GL adapter forwards both integers for `GL_MAX_VIEWPORT_DIMS` from host Mesa. The previous adapter wrote only the first: in the observed run, the renderer's `OpenGLRenderer::InitParameters` queried maximum texture size and maximum viewport dimensions, then stored their elementwise minimum at renderer offset `0x4bc1c`. The incomplete query produced limits 16384 by 0, so a 192 by 192 texture creation took the native exception path. The complete Mesa maximum-dimensions query returned 16384 by 16384. The probe asserts both dimensions support this control; values depend on the host.

This is single-threaded ARM64 emulation with host Mesa, not the application's scheduler. The queue passes through a host context-query intervention, the manager canvas factory returns the host-created native canvas, and the framebuffer is bound for readback. Locks and logging remain stubbed; compare-and-swap and pointer exchange use host adapters. `strtof` uses the host C library and process locale; its errno and other host environment behavior are not modeled in the emulated process. The `posix_memalign` adapter models only successful, bounded allocation from the emulator heap and does not establish full allocation or free semantics. The inherited wrapper creates temporary files under the project directory, and the complete runtime environment is not pinned. The observed instruction sites and slot-8 return do not establish destruction or resource lifetime. No concurrent scheduling, normal GL-thread startup, saved-page traversal, device behavior, or new Rust, SVG or PDF comparison is established. Mesa and its transitive dependencies are not fully pinned. The probe pins the renderer, upstream v254 harness and fixture; the prepared harness pins its native libraries, including libc++.
