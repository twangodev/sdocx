# Manager RGBA framebuffer control

After the v219 preparation, run `python3 tools/pencil2-worker-v274/probe.py` and `PENCIL_SKIP_DRAW=1 python3 tools/pencil2-worker-v274/probe.py`. The wrapper pins v273 and changes the native manager's supplied texture layouts to 6 and 2, including the ninth argument in the emulated stack slot. It retains v273's native factory, manager map, deferred message and framebuffer attachment assertions. The manager's native factory requests RGBA8/RGBA/UNSIGNED_BYTE. On this host the before readback is transparent; Run changes 322 bytes, and the captured 192×192 RGBA bytes equal the v256 fixture byte for byte (bottom row first; SHA-256 `a0230ba18bf716851b4079facb415b265ade62b80ef28bbfcaa0b1853776672e`). Skipping Draw changes no bytes. Null-data initialization and Mesa are host-dependent.

`python3 tools/pencil2-worker-v259/compare.py` compares the same fixture with source-driven Rust and passed byte for byte after the row-order conversion. The v259 actual SVG and direct PDF alpha comparison was rerun with `PYTHONPATH=/tmp/stat324-hw5-pdf-zVkzjl/verify/lib/python3.14/site-packages .venv/bin/python tools/pencil2-worker-v259/export_compare.py`: resvg and PDFium matched every alpha pixel, while MuPDF differed at 80 pixels by one alpha level. This uses the existing local reader environment and compares alpha only. This equality connects those bounded comparisons to this manager capture, but does not establish a real page's layout choices, saved-page traversal, automatic queue lifecycle, object destruction, device fidelity or full-color SVG/PDF fidelity. The synthetic deferred message substitutes the manager canvas and initializes the drawable explicitly. See v273 and v259 for dependencies, matrices, and detailed boundaries.
