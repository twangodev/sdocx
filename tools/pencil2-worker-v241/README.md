# Synthetic Pencil2 async worker iteration

`python3 tools/pencil2-worker-v241/probe.py` verifies the retained [receipt](enqueue-receipt.json); pass `--write-receipt` to regenerate it. Native submission enqueues one synthetic request. The harness moves its list links into the Drawing DSO singleton globals and invokes `ObjectAsyncDrawingImpl::EventLoop`. Native code selects the request, calls `draw`, reaches a distinct four-point Pencil2 clone, V14 RedrawPen and 84 AddPoint calls, and passes the caller's Matrix3 to two setters. It then unlinks the queue node, reduces the queue count to zero, leaves both sentinel links pointing to the sentinel, reaches the destructor call site and signals completion. The destructor implementation is a host callback and is not exercised. The harness stops execution at the loop back-edge.

The native EventLoop instructions also show an empty-queue wait, a canceled-request branch, unlocking around `draw`, and reacquisition before removal. Only the non-canceled path is exercised. Critical sections, condition signaling, and the request destructor are host callbacks; bitmap, graphics, allocation, context and reference operations are synthetic. The queue transplant is an explicit intervention, and there is no concurrent thread or real condition wait. This does not establish normal scheduling, ownership, a Matrix4 handoff, GPU paint, saved-page behavior, or device output. The receipt pins selected inputs, not every transitive dependency.
