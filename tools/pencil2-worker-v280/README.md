# Native AGLL queue round trip

Run `python3 tools/pencil2-worker-v280/probe.py` after the v219 preparation. The script pins the Renderer DSO and runs its ARM64 `AGLLThreadGLImpl::enQueueMsg` (RVA `0x4fbf0`) and `RunTasks` (`0x4fac8`) in Unicorn. It supplies a synthetic initialized queue and two synthetic tasks, stubs the lock and log calls, and implements the pointer exchange as a single-threaded host callback. Both native enqueue calls return 1; native drain invokes each task's vtable slot 16, then slot 8, in FIFO order. The queue returns to its empty sentinel state and a second drain invokes nothing.

Static disassembly shows enqueue uses an intrusive link at task +8 and chooses a 24-byte queue using the index at renderer +136. `RunTasks` calls the shared native dequeue at `0x46b58`, then the two task slots; its final log call is stubbed. The supplied tasks' slot functions only record calls; slot 8 does not destroy them: this does not exercise the Pencil2 render message, actual thread synchronization, renderer construction, GL context, saved-page scheduling, or device behavior. The initialized queue and its owner are synthetic, and the pointer exchange callback is not an atomicity or concurrency test. Unicorn and host runtime dependencies are not fully pinned.
