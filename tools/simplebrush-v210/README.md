# SimpleBrush size-three 65-point controls

The experimental public-export generator and replay callers have been retired. Export hashes and external SVG/PDF reader measurements below are historical observations, not current reproduction instructions or full source/build attestations. Native capture commands, inputs and receipts remain retained.

Two fresh 65-point tool-0, size-3 synthetic captures use the fractional 2× host transform. The baseline follows the existing export fixture. The alternate uses a distinct fully visible path with x = 27 + i and pressure-varying input. The compressed receipts retain the full native JSON and corresponding RGBA frame; they do not establish device or saved-page parity. Native execution depends on the project-local scratch inputs and runtime, which are not fully pinned.

Run `POINT_COUNT=65 PROBE_SIZE=3 python3 tools/simplebrush-v210/capture.py fraction12 /tmp/NEW/native.json --tool 0` for the baseline, or set `VARIANT=alternate` for the visible alternate. The directory must exist and its `native.json` and `captures` must not exist. The script pins its native library and source capture inputs and checks the GL paint verdict.

A historical verifier replayed native data and compared SVG and PDF output; its experimental patches and verifier have been retired. The current explicit 2× profile admits tool-0, size-3 strokes through 128 points; coverage for other inputs remains bounded by the current tests. The 65-point candidate reduced baseline SVG alpha error from 313,617 to 4,681, MuPDF matched-paper RGB error from 343,932 to 29,994, and PDFium RGB error from 345,344 to 50,361. The visible alternate reduced those errors from 488,920 to 10,409, 534,557 to 47,519, and 536,390 to 66,661 respectively. An earlier exploratory comparison of its 64- and 65-point candidate SVG rasters reported 34 changed pixels; this observation is not replayed by the retired verifier. These controls do not establish general path parity.
