# Marker3 saved tolerance trace

`caller.py` is the note-derived native Drawing capture with an additional Unicorn hook at `Marker3StrokeDrawableGLV5::drawLine`. It records the phase, input XY f32 bits, tool flag, drawable +48, tolerance +44, spacing +88, residual +92, alternation +104 and four coordinates at +116. `drawline-state.txt` contains two repeated captures (55 lines per phase per capture). The native Model object was created through setters without setting initial tolerance; both Drawing and saved-redraw calls observed +44 = 0.0. The source geometry is note-derived, but the tolerance is the synthetic Model default, not evidence of the original note's saved tolerance.

ObjectStroke `RedrawPen` in `libSPenMarker3.so` at 0x3e370–0x3e378 calls `GetInitialToloerance()` and stores its result at drawable +44 before `redraw`. The native Model getter at 0x2e24a0 reads model +356, and the setter at 0x2e244c stores the supplied f32. The earlier lower-level fixture instead inherits the drawable constructor's +44 = 2.0 at 0x3cd80. Native `drawLine` compares distance strictly below +44 at 0x3e0c8–0x3e0d0; for tool 1, passing this check permits zero-distance samples to toggle the alternating flag.
