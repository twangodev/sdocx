# StraightMarker tool 1 empty setting at 4×

Fresh paired synthetic Drawing captures test a non-null empty setting against literal `5;`, at widths 4, 6 and 8, phases 0, 0.5 and 0.25 output pixels, and short, fractional and crossing paths. `native.json` retains the inputs, getter readbacks, native vector and framebuffer hashes, draws, host and library identity. `verify.py` checks matched native inputs and public export inputs, native getter values, every callback's coordinates and count, complete final Drawing and saved-redraw vector bytes, draw/upload metadata, and every byte of the 512×512 host framebuffer. It excludes allocation addresses when comparing callback records. Both settings selected V5 and all GL checks passed.

Each case receipt compares the empty-setting public 4× SVG and direct PDF with a generic-name fallback at the same output scale. The native transparent framebuffer is the SVG reference; PDF reference pixels are mathematical composition of that frame over #fcfcfc. Resvg, MuPDF and PDFium each have lower aggregate error for the admitted output in every case, with zero missing native SVG support pixels. MuPDF errors include a reader paper difference. Reader versions and export hashes are in the receipts. PDFium here is 5.9.0 / 150.0.7869.0, distinct from the earlier literal-setting comparison.
