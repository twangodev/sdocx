# Marker3 tool-1 size-9 controls

Three synthetic Model/Drawing strokes use reversal, crossing and short-turn trajectories with translucent red, opaque blue and translucent green. Each was captured at 1×, 2× and 4× using the explicit native vector bridge and host Mesa described in `../marker3-terminal/README.md`. The readable `caller-provenance.json` reconstructs every original caller field together with the fixture in `conformance/marker3-size9-diverse-native.json`, which retains the original input arrays and both complete Drawing and saved-redraw vectors. Each vector matches the Rust sampler bit for bit, and vectors and input records agree across all three scale captures.

The verifier checks complete reconstructed-document hashes, vector hashes and capture field hashes. Callback coordinate histories reuse exact native-vector prefixes; ordered lifecycle changes retain every register, getter and runtime field. Original gzip and JSON byte hashes remain historical identities; archive formatting is not reconstructed. Frame bytes and SHA-256 digests are retained; these are not serialized-note or device captures.

The historical receipt compares public SVG (resvg) and direct PDF (MuPDF and PDFium), using the captured transparent native frame and its mathematical composite over #fcfcfc. All nine cases reduce aggregate error relative to the paired generic fallback, both for default admitted output and the explicit scale option. The admitted outputs miss no native SVG support pixels; the generic fallback misses 102–8858. MuPDF error includes its paper conversion. This supports the size-9 admission; intermediate sizes, other trajectories, backgrounds, devices and notes remain extrapolations.

On the prepared capture host, `.venv/bin/python tools/marker3-size9-diverse/capture.py /tmp/marker3-size9-diverse` regenerates the nine frames and caller records. It requires the local inputs and incomplete dependency closure described in `../marker3-terminal/README.md`. Compare decompressed frames against `receipt.json` hashes. Verify the retained caller reconstruction, native vectors and all nine frame hashes with `python3 tools/marker3-size9-diverse/verify.py`.

The archive replay, exporters and reader comparator have been retired. Receipt source/build hashes and reader measurements remain historical; they do not pin the complete build or reader dependency closure. The maintained Rust `size_nine_diverse_native_vectors_and_gate` test checks native vectors and admission boundaries, separately from these historical reader measurements.
