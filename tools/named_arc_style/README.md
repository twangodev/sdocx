# Saved Arc with solid outlines

This capture varies the moved Arc outline: width 0.5 with color `0x80009955`, and width 12 with color `0xffcc6622`. Native Model writes and reloads each frame. Native Drawing calls SkPaint setStrokeWidth with the selected width and submits a center-closed sector in opaque red followed by the open outline with the selected packed color. The setter arguments are recorded at call entry; subsequent paint mutation is not separately inspected. Five runs with allocation fills 0, 85, 165, 255, 0 match their complete receipts and frames. SVG tests check the separated paths, outline color and width, and translucent outline opacity. PDF tests check separate fill and stroke operators and the translucent outline's active opacity. All positive finite widths and solid colors extrapolate from these two controls; zero-width, dashes, arrows and other unsupported effects retain fallback.

Run `python3 tools/named_arc_style/replay.py /absolute/path/to/arm64-v8a /absolute/path/to/unicorn/lib`. The replay checks all rustc-reported dependencies and the Unicorn library against the hash manifest; native libraries and host libm are checked by the capture. The compiler is not pinned. Bounded host substitutes record canvas path submissions, and reached PLT destinations are audited; indirect calls are not audited. This does not execute native device Canvas, raster pixels, full document loading or native PDF export. SVG/PDF tests verify structure and paint transport, not pixel parity.
