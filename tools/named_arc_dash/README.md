# Native saved dashed Arc outlines

The probe creates a moved type-20 Arc with red fill, width 6 and translucent `0x80009955` outline, sets each named dash 1–7, then writes and reloads the native frame and records Drawing path submissions. It runs the native Skia dash constructor and `SkPaint::setPathEffect`: the second submitted paint retains the effect pointer and the first has none. The native constructor intervals and phase match the existing line-style capture, while path submissions remain the center-closed sector and separate open outline. Allocation fills 0, 85, 165, 255, 0 reproduce each complete receipt and frame.

Run `python3 tools/named_arc_dash/replay.py /absolute/path/to/arm64-v8a /absolute/path/to/unicorn/lib`. The source manifest covers the full rustc dependency set and the Unicorn library is pinned. The probe pins native libraries and host math, uses bounded memory and host substitutes, and audits reached PLT bindings. Indirect targets are not audited and compiler version is not pinned. The canvas is a recording substitute; this does not execute device rasterization, a full document load or native PDF export. SVG and PDF tests assert paths, dash parameters and alpha transport, not pixel parity. Widths other than 6 and colors beyond this control extrapolate from previously captured solid-outline and style-setup controls; compound, arrow, nondefault cap and join styles remain excluded.
