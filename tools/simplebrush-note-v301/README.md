# SimpleBrush tool 0 short-terminal controls

The 57 positions and pressures are from Fountain stroke 29, translated and rounded as in `simplebrush-note-v300`; this is not a saved Brush stroke. The captured ObjectStroke uses Brush tool 0, empty advanced settings, color `0x8044aaee`, a 2x matrix with fractional translation, Unicorn native Drawing, and host Mesa. The reverse control reverses both arrays. The uncompressed native frame and complete native geometry hashes are retained in `conformance/simplebrush-note-v301.json`; the size-8 frame is compressed beside this file. Capture dependencies and limitations are as described in `../simplebrush-note-v300/README.md`.

The tool-0 short-terminal exclusion was a conservative coverage boundary introduced during early profile expansion; earlier commits gradually admitted captured short paths. The sampler's native movement comparison is shared by tools 0–3. The 2x long-stroke public dispatch remains limited to size 8–20, while the 1x and size-3 terminal exclusions remain intact. The note-derived cases matched the entire native sample vector byte-for-byte. For size 8, generic versus 2x-profile SVG alpha L1 was 60268 versus 998; matched-paper MuPDF RGB L1 was 66680 versus 4946, and PDFium was 66434 versus 7016. For reversed size 8 these were 59187 versus 846, 65358 versus 4945, and 65082 versus 7485. For size 20 they were 176558 versus 2090, 193417 versus 9305, and 193314 versus 12812. Size 4 and 32 are outside long-stroke public dispatch and fell back. These aggregate host comparisons do not establish pixel parity, device rendering, or arbitrary note-page composition.

Reproduce each note capture using `POINT_COUNT=57 PROBE_SIZE=8 python3 tools/simplebrush-note-v301/capture.py fraction12 /tmp/OUT/native.json --tool 0`; set `REVERSE_NOTE=1` for the reversed path and choose size 4, 20 or 32 as needed. The public fixture and comparison commands are in `../simplebrush-note-v300/README.md`; use `SDOCX_TOOL=0` and set `SDOCX_REVERSE_NOTE=1` for the reversed case.

A synthetic self-crossing path uses the same 57 note pressures and a duplicate terminal, with getter-verified native points, pressures, timestamps 0–56, and zero tilt and orientation arrays. The public fixture has empty timestamp and stylus arrays; the sampler does not use timestamps. All 224 native and reconstructed positions match bit-for-bit; three radii differ by 2, 4, and 6 ULP. An otherwise identical open-terminal crossing, admitted before this change, has 228 samples and the same three radius differences, so this is not introduced by the terminal admission; the arithmetic cause is unproven. Generic versus candidate SVG alpha L1 is 646971 versus 8388, matched-paper MuPDF RGB L1 710111 versus 52322, and PDFium RGB L1 714209 versus 90760. A second color (`0x80e04020`) on the note-derived path also matches the native vector, with MuPDF RGB L1 104081 versus 7581 and PDFium 103481 versus 10667. These controls support an approximation, not universal exact geometry.

For the crossing capture, set `CROSS_NOTE=1` for the capture command; add `CROSS_OPEN=1` for the already-admitted open terminal. Set `SDOCX_CROSS_NOTE=1` in the public fixture and additionally `SDOCX_CROSS_OPEN=1` for open terminal. Omit `SDOCX_V62_NATIVE` for these crossing exports because that fixture asserts byte-exact samples, while the separate bounded geometry test checks the documented radius differences. For the alternate-color control use `ALT_COLOR=1` in the capture and `SDOCX_ALT_COLOR=1` in the public fixture; the latter can retain the exact-vector assertion. Export comparisons use the `simplebrush-long-expanded/compare.py` and `simplebrush-note-v300/pdfium.py` commands described by the v300 README.

For example, from the repository root on the prepared host:

```sh
mkdir -p /tmp/simplebrush-v301-cross /tmp/simplebrush-v301-color
CROSS_NOTE=1 POINT_COUNT=57 PROBE_SIZE=8 python3 tools/simplebrush-note-v301/capture.py fraction12 /tmp/simplebrush-v301-cross/native.json --tool 0
CARGO_TARGET_DIR=/tmp/sdocx-agent-target CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 CARGO_BUILD_JOBS=2 SDOCX_SIMPLEBRUSH_NOTE29=1 SDOCX_CROSS_NOTE=1 SDOCX_TOOL=0 PROBE_SIZE=8 SDOCX_SIMPLEBRUSH_TWO_EXPORT=/tmp/simplebrush-v301-cross cargo test -p sdocx --features pdf,serde --lib two_pixel_native_export_fixture
ALT_COLOR=1 POINT_COUNT=57 PROBE_SIZE=8 python3 tools/simplebrush-note-v301/capture.py fraction12 /tmp/simplebrush-v301-color/native.json --tool 0
CARGO_TARGET_DIR=/tmp/sdocx-agent-target CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 CARGO_BUILD_JOBS=2 SDOCX_SIMPLEBRUSH_NOTE29=1 SDOCX_ALT_COLOR=1 SDOCX_TOOL=0 PROBE_SIZE=8 SDOCX_V62_NATIVE=/tmp/simplebrush-v301-color/native.json SDOCX_SIMPLEBRUSH_TWO_EXPORT=/tmp/simplebrush-v301-color cargo test -p sdocx --features pdf,serde --lib two_pixel_native_export_fixture
.venv/bin/python tools/simplebrush-long-expanded/compare.py /tmp/simplebrush-v301-cross
PYTHONPATH=/path/to/pypdfium2 .venv/bin/python tools/simplebrush-note-v300/pdfium.py /tmp/simplebrush-v301-cross
```

The same two comparison commands accept `/tmp/simplebrush-v301-color`. `CROSS_OPEN=1` and `SDOCX_CROSS_OPEN=1` select the open-terminal control in the corresponding commands.
