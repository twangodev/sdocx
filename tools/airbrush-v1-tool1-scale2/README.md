# AirBrush V1 tool 1 scaled-input control

This is a fresh synthetic Model/Drawing host-Mesa capture, not a resampled 256-pixel frame. It doubles both coordinates and size of the reverse control (size 2.25 to 4.5) and uses a 512 × 512 native bitmap. The compressed native premultiplied frame, input arrays and native stamp events are in `receipt.json`. The capture uses the same pinned native prerequisites as `../pen-capture/airbrush_v1_curved_prerequisites.json`; these local dependencies are not part of a clean checkout. The capture runs native Drawing with a synthetic page matrix and host callbacks, not an Android device or saved note.

In the historical export experiment, all 848 sampled stamp bytes equal the native stream. The public SVG rasterized by resvg has zero RGBA absolute error against the native frame. At 96 dpi, the direct candidate PDF has MuPDF premultiplied RGBA error 5421 and PDFium alpha / white RGB errors 2216 / 3646; generic errors are 8977 and 3788 / 12219. Inserting the independently generated candidate SVG raster as one PDF image yields 377 and 0 / 297. This image-transport experiment uses the source-derived resvg PNG, not the native frame, and is not the direct vector PDF. It does not justify raster promotion. Scaling the source stroke tests a different input at a larger size; it does not establish arbitrary viewer zoom, ordered overlap, scene behavior, or device fidelity.

To replay the native capture, run `.venv/bin/python tools/airbrush-v1-tool1-scale2/capture.py /tmp/airbrush2x-native-new.json`; the output must not exist. Its first `FRAME_STATE` record contains the native frame and its second JSON record contains the producer events. The runner and prerequisite hashes are checked before execution. Compare the frame SHA and stamp bytes with the receipt; the full raw JSON includes runtime addresses.

The experimental patch and export comparator for revision `417cab5c` have been retired. Besides enabling V1 tool 1, the patch incidentally changed V2 tools 0 and 3 sampling to use their actual tool types instead of tool 2; this control did not validate those changes. The historical reader measurements used PyMuPDF 1.28.2, Pillow 12.1.1 and PDFium 150.0.7869.0. They do not justify promoting the patch wholesale.
