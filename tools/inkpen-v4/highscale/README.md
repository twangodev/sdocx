# InkPen V4 5–8× host controls

Twelve synthetic native host-Mesa captures exercise straight, bent, and crossing strokes at 5–8×. The native input and compressed RGBA frames are in `conformance/inkpen-v4-highscale-native.{json,bin}`. `comparison.json` records alpha error for public SVG via resvg and RGB error for direct PDF via MuPDF, with native RGBA composited over #fcfcfc. Every scale-aware contour improves over the same V4 profile using the 1× contour. These are synthetic opaque controls; device pixels, arbitrary transforms, and saved-note parity remain unverified. MuPDF includes a substantial background/color conversion baseline.

Capture with the repository's native inputs and dependencies as described in the parent README. For each scale 5 through 8, set `INKPEN_CAPTURE_SCALE` and `INKPEN_CAPTURE_BENT` to `straight`, `1`, and `loop`, and save the capture as `<scale>-<shape>.json` in a temporary directory. Run `python3 tools/inkpen-v4/highscale/pack.py <directory>` to create `packed.json` and `packed.bin`; compare frame and stream hashes to the retained native fixture. Capture JSON hashes and host addresses may vary across runs. `straight` leaves the original source trajectory unchanged. The packer validates each native frame hash and dimensions.

For export comparison, insert the test in `export-probe.rs.txt` into the existing `ink::inkpen::tests` module in a disposable checkout, set `SDOCX_V4_HIGH_DIR` to the same directory, and run the named test with the `pdf` feature and the shared target settings. Run `python tools/inkpen-v4/highscale/compare.py <directory> <resvg-helper>` with Pillow, NumPy and PyMuPDF installed. The comparator uses the native input, validates frame hashes, and writes `comparison.json`; values may vary with reader versions. The comparator asserts both errors improve and records the source renderer hash, export hashes, and reader versions. The probe explicitly selects `4;`, while the native capture uses the empty V4 setting; geometry and this setting pairing are bounded to these controls.
