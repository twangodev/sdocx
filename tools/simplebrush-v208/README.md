# SimpleBrush tool-0 short size-3 controls

The experimental public-export generator, comparators and replay callers have been retired. Export hashes and external SVG/PDF reader measurements below are historical observations, not current reproduction instructions or full source/build attestations. Native capture commands, inputs and receipts remain retained.

Two synthetic host-Mesa Drawing captures use size 3, tool 0, four and seven points, constant pressure 0.5, and the fractional 2× matrix. The capture script is adapted from `simplebrush-v195` to match the public export fixture's short-path coordinates. Retained vectors match the Rust sampler byte for byte. The compact frames are zlib-compressed RGBA8; `native-*.json` contains the vector and frame digest. Native adapter dependencies are not fully pinned.

For each count `N` in 4 and 7, reproduce with `POINT_COUNT=N PROBE_SIZE=3 python3 tools/simplebrush-v208/capture.py fraction12 /tmp/NEW/native.json --tool 0`, after creating `/tmp/NEW` and ensuring its `native.json` and `captures` do not exist. The historical PDFium comparison used an unshifted grid. The 2× profile's resvg alpha absolute error was 2,647 versus 69,454 fallback for four points and 4,601 versus 124,786 for seven. MuPDF matched-paper RGB error was 11,112 versus 76,642 and 19,802 versus 137,749. PDFium 156.0.8076.0 RGB error was 21,412 versus 76,299 and 39,051 versus 137,041. resvg was 0.45.1 and MuPDF 1.28.2. These are selected host controls; other admitted paths, point counts and device or saved-page rendering remain unverified.

A clean archive of commit `86df8b5277e4cf9a3a5dbe1642cfeb9fb776dbec` with the two SimpleBrush admission changes and their regression tests reproduced all checks; the receipt pins those candidate source files by SHA-256 and the retired verifier checked them. Its native capture inputs remain dependent on project-local scratch and native libraries.
