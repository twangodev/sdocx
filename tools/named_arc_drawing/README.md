# Saved Arc Drawing recording controls

This synthetic Unicorn probe constructs native Model Arc shapes, sets solid fills, writes and reloads each native frame, then invokes native Drawing `ObjectShapeDrawing` Construct, SetObject, SetEffect and inner `drawPath`. The controls are a wide ellipse with opaque red fill, a circle with opaque blue fill, and a tall ellipse with half-alpha red fill. For each, native Drawing submits a center-closed sector with that packed color followed by the open black outline. The frame, active SkPath verbs and points, paint color, allocation event counts, host call counts, and reached PLT targets agree across allocation fills `[0,85,165,255,0]`.

```sh
tools/named_arc_drawing/replay.sh /absolute/path/to/arm64-v8a /absolute/path/to/unicorn/lib
```

The probe supplies a null context and a synthetic CanvasBitmap with a recording canvas. Canvas save, scale, translate, restore, and path output are host substitutes; the callback snapshots SkPath object bytes and inspects the shallow copy after native draw returns. Its bounded bump allocators do not reuse freed storage. Paint color is read at SkPaint +92, the field used by native Skia `setColor`. The shared chronological ledger checks exact allocation/free ownership, not arbitrary native memory reads for use-after-free. Native code, bounded allocations, deterministic UUIDs, single-thread synchronization, logging, memory/string services and pinned host libm are the remaining boundaries. This does not execute a device canvas, native rasterization, final pixels, full document loading or native PDF export, and does not prove general shape or device parity.

Replay pins the capture and two main harness source files plus the Unicorn soname; other included Rust modules and compiler are not pinned. Model, Base, Skia, libc++, Drawing, PenCommon and host libm hashes are checked by the probe. The optional audit reads original ELF relocations and validates recorded actual PLT PC-to-target pairs against native symbols or an explicit host-service list. It does not audit non-PLT indirect targets or establish general ABI correctness. Drawing and PenCommon bindings were reduced to the reached targets from these controls, with unbound imports trapping. See the stored receipts and target trace for the observation boundary.

The renderer admits solid-filled type-20 paths only when their zero-rotation, unflipped default controls and normalized outline match the Model default arc and their outline is the captured opaque-black, width-2, simple butt/miter style. Matching other finite positive rectangles and solid colors extrapolates from these three controls. Other styles, moved controls, nonmatching normalized paths, changed saved owner/drawn bounds and rotations keep the generic renderer; their parity is not established by this capture.
