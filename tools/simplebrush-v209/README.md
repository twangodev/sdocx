# SimpleBrush size-three alternate trajectory

A fresh synthetic 64-point tool-0, size-3 Drawing capture uses the alternate pressure-varying trajectory and fractional 2× transform. The public export fixture checked its complete native vector byte for byte. The existing 2× route reduced resvg alpha error from 531,930 to 14,169, MuPDF matched-paper RGB error from 578,720 to 61,389, and PDFium unshifted RGB error from 581,037 to 99,945. Reader versions and export hashes are in `receipt.json`. This extends evidence within the existing gate; it does not justify admitting additional sizes, phases, or lengths, and does not establish device or saved-page parity.

To reproduce, create an empty output directory and run `POINT_COUNT=64 VARIANT=alternate PROBE_SIZE=3 python3 tools/simplebrush-v208/capture.py fraction12 /tmp/NEW/native.json --tool 0`, then `SDOCX_POINTS_COUNT=64 VARIANT=alternate PROBE_SIZE=3 SDOCX_TOOL=0 SDOCX_V62_NATIVE=/tmp/NEW/native.json SDOCX_SIMPLEBRUSH_TWO_EXPORT=/tmp/NEW cargo test -p sdocx --features pdf,serde two_pixel_native_export_fixture --lib` with the project shared Cargo settings. Run `tools/simplebrush-size3-32/compare.py /tmp/NEW` with its pinned dependencies. The PDFium comparison uses `tools/simplebrush-v209/pdfium.py`, which reuses the v208 comparator with an explicit version 150.0.7869.0 check; it uses an unshifted grid. The capture relies on project-local native dependencies that are not fully pinned. The compressed complete native receipt and frame are retained here.

With resvg 0.45.1 on PATH and a Python environment containing PyMuPDF 1.28.2, PDFium 150.0.7869.0 via pypdfium2, and Pillow, run `python tools/simplebrush-v209/verify.py` to archive clean revision `f1b372fe`, regenerate exports, and verify native geometry, export hashes, and reader metrics in a temporary directory. This clean-source replay passed.

The verifier replays retained native data; it does not run a fresh native capture. Comparator scripts come from the archived source revision. It clears inherited `SDOCX_*` controls before setting fixture inputs. Reader binaries and Python packages are external prerequisites; their versions are checked by the comparators.
