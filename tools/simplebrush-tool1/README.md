# SimpleBrush tool 1 host controls

The experimental public-export generator and replay callers have been retired. Export hashes and external SVG/PDF reader measurements below are historical observations, not current reproduction instructions or full source/build attestations. Native capture commands, inputs and receipts remain retained.

Synthetic native Drawing/Mesa captures use the pinned script and library inputs checked by `capture.py`; transitive runtime dependencies are not independently pinned. The capture wrapper here adds tool 1, edge translation and short-movement inputs. It needs the project-local scratch inputs named in the wrapper. These controls do not establish device or saved-note behavior. The production gate admits tool 1 only for 3–32 points at sizes 8–12. The 2× profile assumes the caller's axis-aligned output scale assertion.

`receipt.json` records native vector and full-frame hashes and candidate versus generic public SVG and direct PDF comparisons. The candidate used an isolated copy with the same bounded gate. SVG was rasterized by resvg 0.45.1; direct PDF was rasterized by MuPDF 1.28.2 against the matched blank page. The edge vector differs in low f32 bits, while its rendered comparison improves. The short movement is rejected by the existing geometry gate and retains generic rendering. Other counts, sizes and trajectories within the gate extrapolate from these four synthetic paint controls. PDFium and opaque native backdrops were not tested.

Run captures from the repository root, with an existing fresh output directory: `SDOCX_ROOT="$PWD" POINT_COUNT=16 PROBE_SIZE=8 python3 tools/simplebrush-tool1/capture.py fraction12 /tmp/output/native.json --tool 1`. Use `POINT_COUNT=3 PROBE_SIZE=12`, `POINT_COUNT=32 PROBE_SIZE=12 VARIANT=reverse`, `POINT_COUNT=16 PROBE_SIZE=8 EDGE=1`, or `POINT_COUNT=3 PROBE_SIZE=8 SHORT=1` for the remaining controls. The capture relies on ignored scratch source and the named local native library; preserve those prerequisites when reproducing. Full native RGBA frames are retained compressed, and geometry bytes for regression are in the crate fixtures. The short capture uses three native points `(32, 32)`, `(32.25, 32)`, `(32.5, 32)` and pressures `0.5`. The generator rejects that movement before public export, so it has no candidate SVG/PDF comparison in the receipt.

The short frame is byte-identical to `../simplebrush-note-v300/tool1-short.rgba.zlib` and is retained there. The 3-point, 32-point and capture VBOs are retained in `../../crates/sdocx/src/ink/fixtures/simplebrush-tool1/`.
