# TapePen size controls

Three fresh synthetic public Drawing captures at size 2, 8, and 16 vary the size of the asymmetric four-point curve at (13,21), (22,29), (34,18), (47,28). They use identity 256×256 bitmap and display, pattern 1, and host Mesa. The [receipt](v249-size-receipt.json) records input, native hashes, actual uniform words and framebuffer hashes; compressed native frames are comparison-only. The local, uncommitted `phase-replay.py` was the capture script; the receipt records its command. Native recapture therefore requires that external script in addition to the native assets. This is not a saved-note or Android control.

The observed radii equal `(size/8,size/2)` and the vertex half extents are consistent with those radii multiplied by `1 + AA`, where AA is the existing native-size-level calculation. Pattern period is (64,64), phase is (13,21), and shadow displacement in pixel coordinates is approximately `(0.0225*size,0.025*size)`; the recorded floating-point uniforms include native rounding. These are bounded observations and approximate candidate formulas, not a native dataflow derivation or proof for other settings and transforms. In particular these three runs vary size, not geometry, position or display.

The `v249_size_source_mask` test derives the stream and mask from source points and these candidate formulas. `v249-size-diagnostic.py` rasterizes the caller's hash-checked SVG asset and combines the derived mask and pattern without captured intermediate pixels. All three masks match the retained native intermediate mask alpha bytes exactly. Compared with the retained native frames, resvg premultiplied RGBA absolute error sums are 11, 20 and 13 respectively, maximum 1. SVG-derived MuPDF sums are 130, 356 and 603, maximum 3, 2 and 2; PDFium on white sums are 154, 342 and 582, maximum 2, 1 and 1. These are diagnostic SVG-derived PDFs; they do not test the direct document PDF path.

Run `/tmp/sdocx-v190-readers/bin/python tools/tapepen-public-drawing/v249-size-diagnostic.py` with the pinned local pattern SVG, resvg 0.45.1 and readers specified in [v247](v247-README.md). The script builds `asset` and `svg_pdf` from the v248 harness sources and lockfile using the shared agent Cargo target. The script verifies frame hashes and expected reader metrics. The compact receipt retains the original capture logs' SHA-256 identities and selected uniforms. Passing the original size-2, size-8 and size-16 log paths as three arguments checks their exact byte identities, inputs, uniform words, masks and frames against the receipt; newly captured logs are not accepted by this identity check. No captured frame, texture or mask is a candidate input.
