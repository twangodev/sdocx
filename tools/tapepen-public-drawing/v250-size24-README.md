# TapePen size 24 mask control

A fresh synthetic Drawing capture extends the v249 size controls to size 24 on the same asymmetric four-point input, 256 × 256 bitmap and display, pattern 1 and host Mesa. The [receipt](v250-size24-receipt.json) records the input, native library hashes, exact uniform payloads, capture wrapper and full log digest. The local capture wrapper and pinned native assets are prerequisites for recapture. The compressed mask is retained solely as an oracle.

The observed ellipse radii are (3, 12), vertex half extents approximately (3.06, 12.24), pattern period (64, 64), and phase (13, 21). The source-derived stream and candidate size/AA formulas produce an alpha mask identical to all 65,536 captured alpha bytes; `v250_size24_source_mask_matches_native` checks this directly. This extends the bounded mask evidence but does not derive the native dataflow or validate the final composite, direct document PDF, saved notes, other transforms, or Android devices.

Run `python3 tools/tapepen-public-drawing/v250-verify-native.py /path/to/original-size24.log` to check the original log's exact SHA-256, inputs, native identities, uniforms and mask against the receipt and fixture. The original full log is not retained in the repository. Its exact digest identifies this capture; a new capture will have a different log identity and requires its own review. Recapture is not self-contained: `phase-replay.py`, `phase-control.patch`, `size-level-trace.patch`, `capture_candidate.py`, `preflight_candidate.py`, `tapepen_canvas_native.py`, `preflight.json`, `candidate.json` and `phase-receipt.json` are local untracked dependencies, in addition to the pinned native libraries, SVG asset and host runtime. They are not supplied by this control.
