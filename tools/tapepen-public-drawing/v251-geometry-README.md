# TapePen changed-geometry mask control

A synthetic Drawing capture changes the size-24 control to points (13, 21), (18, 10), (31, 30), and (43, 16), with the same 256 × 256 bitmap/display, pattern 1, and host Mesa. The [receipt](v251-geometry-receipt.json) records the native identities, inputs, uniforms and original log digest. The source-derived stream and candidate mask formulas match all 65,536 native alpha bytes in `v251_changed_geometry_source_mask_matches_native`. This is a second path control, not evidence of native dataflow, final composite, saved-document dispatch, direct PDF, other transforms, or Android device parity.

`python3 tools/tapepen-public-drawing/v251-verify-native.py /path/to/original.log` checks the original log against the receipt and compressed oracle. The original log is not retained. [The capture wrapper](v251-geometry-capture.py) records the point intervention, but recapture also requires the local untracked dependencies listed in the v250 README, pinned native libraries, pattern asset, and host runtime. A new capture has its own log identity and requires review. The original capture used the equivalent wrapper in `/tmp` with the project directory resolved explicitly; the retained wrapper resolves it relative to its own location.
