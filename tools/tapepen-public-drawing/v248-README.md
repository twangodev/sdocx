# TapePen 2× source intervention

For the v173 synthetic 2× Drawing capture, the captured intermediate mask has a 512×512 viewport. Its native uniform payloads contain ellipse radii (1.5, 6), vertex half extents (1.77545464, 7.10181856), and the existing source size-level calculation uses the 512×512 display. The final paint draw uses `patternSize=(256,256)`, `grainOffset=(154,118)`, and binds a 256×256 linear-repeat pattern texture. These observations are from the actual Mesa state and do not establish behavior for other displays, transforms or devices. The v247 diagnostic instead used 256-display AA, smaller extents, a 128-pixel period and 64/128 textures.

The 2× source diagnostic applies the captured extent and period, the source-derived AA calculation, and the restricted caller-supplied pattern SVG rasterized at 256. The generated mask differs from the captured mask alpha by one level at one pixel; the generated pattern exactly matches the captured 262,144-byte native texture upload. Captured intermediate bytes are retained compressed for comparison only; they do not generate the candidate. The native upload SHA-256 is `42abf1113cfd13c27f1e0ccb29affae62221c0888f5ffcdc2425e2169b71b13d`; the captured mask alpha SHA-256 is `60cdce6862739174abda6dc8d815ccb738a94016518cde9c95114c21d31d3788`. Native capture and input provenance are in [the v173 native receipt](v173-receipt.json); native intermediate values come from that same capture log, whose SHA-256 is `a9e081c01cf767a31be035d49bd3a47217fb17eec1e9fffa729bd0be91bc6d01`. Run `python3 tools/tapepen-public-drawing/v248-verify-native.py /path/to/2x.log` to verify its v173 inputs and framebuffer, then its actual mask, texture upload, sampler and selected uniforms against these retained bytes. The full log is an external replay prerequisite.

The resvg comparison gives premultiplied RGBA absolute error 73 (maximum 1); SVG-derived MuPDF gives 1,735 (maximum 2), and SVG-derived PDFium on white gives 1,624 (maximum 2). The v247 64-texture results are 60,203, 60,967 and 48,773 respectively. These PDF controls convert the candidate SVG and are not direct document PDF. Pixel-grid output and captured constants remain diagnostic, not public document dispatch. The comparison is one synthetic host control, not saved-document or device parity.

The export comparator has been retired; the reader measurements above are historical. The native intermediate verifier and retained captures remain.
