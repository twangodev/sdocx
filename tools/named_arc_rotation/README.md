# Saved rotated Arc replay

Run `python3 tools/named_arc_rotation/replay.py /absolute/repository /absolute/arm64-v8a /absolute/unicorn/lib`. This patches the cap/join capture in a temporary directory and checks its complete rustc dependency set, native-library and host-math checks, Unicorn, hashed receipts and frame buffers. The compiler is not pinned. Four allocation fills (0, 85, 165, 255) and a repeat at zero cover the moved controls described in the findings. A prefilled writer buffer shows that four extra bytes for nonzero rotation remain untouched; the loader is given and consumes exactly the three framed lengths. The recorded canvas substitutes for device drawing. Reached PLT targets are recorded, but indirect calls, Android math, whole-document loading and native PDF appearance remain outside this evidence.
