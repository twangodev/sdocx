# Marker3 tool-1 size 9 exploratory controls

Two synthetic size-9 strokes exercise a short turn and a self-crossing path at 1× with fractional input coordinates. `capture.py OUTPUT` adapts the pinned native Model/Drawing and RTV1 bridge in `../marker3-zero`; it uses the same local dependencies and hash checks. The same retained Drawing vector is explicitly bridged into the selected native RT after the wrapper clears its slots. Mesa llvmpipe paints the transparent frame; this is not device or saved-note parity. Compressed native frames and caller cases, compact native receipts, hashes, and reader versions are retained here.

`PYTHON=/path/to/python PYTHONPATH=/path/to/pypdfium2 tools/marker3-size9-exploratory/replay.sh` makes a temporary source copy, expands the size gate only there, checks candidate XY bits against both native Drawing and saved-redraw vectors, and compares public SVG and direct PDF against the native transparent frame and mathematical #fcfcfc composition. It uses the shared agent Cargo target. The offline Cargo cache must contain all dependencies in both retained lockfiles. The Python environment needs NumPy, Pillow, PyMuPDF, and pypdfium2; resvg must be on PATH. The comparator records actual reader versions. It keeps temporary exports only for the run.

On these captures the baseline and candidate SVG, MuPDF and PDFium aggregate L1 errors respectively were 14811/43626/15464 versus 6689/37360/6347 for the short stroke, and 54252/71810/55975 versus 19325/46686/26118 for the crossing. Both modes cover all native support. The candidate is exploratory: two 1× cases do not establish a width interval, other phases, 2× behavior, arbitrary transforms, or device parity. Production admission stays unchanged.

Replay uses Git commit `4361933850036a3c2e5a333814f04b499f47fe6a`, two retained lockfiles, and a temporary one-line size-bound patch plus the geometry assertion; it verifies fixture hashes, exact reader versions and exact aggregate metrics. The native capture requires the pinned APK DSOs, local Python runtime, Unicorn, AArch64 binutils, Mesa/EGL, and ignored helper tree checked by `../marker3-zero/hashes.json`. These host-local inputs are not distributed here, and the complete dynamic runtime dependency closure is not pinned; this is not a clean-checkout native acquisition recipe. The matrix is identity in both captures; fractional phase comes from the different input coordinates, not an additional output translation. The captured caller JSON and frame are inputs to replay; replay does not rerun native capture.
