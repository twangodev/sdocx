# SimpleBrush alternate-path control

The experimental public-export generator and replay callers have been retired. Export hashes and external SVG/PDF reader measurements below are historical observations, not current reproduction instructions or full source/build attestations. Native capture commands, inputs and receipts remain retained.

Synthetic tool-3, size-20, 32-point alternate-path Drawing capture under the project-local host Mesa setup, with the fractional 2× matrix. The capture adapts the original local runner so this input matches the public fixture's 32-point alternate coordinates. It retains the compressed RGBA8 frame and vector plus hashes and paired reader measurements in `receipt.json`.

Reproduce the native capture with `POINT_COUNT=32 VARIANT=alternate PROBE_SIZE=20 python3 tools/simplebrush-v195/capture.py fraction12 /tmp/simplebrush-v195/native.json --tool 3`, creating the directory first; the output file and its sibling `captures` directory must not exist. The test checks every native vector byte before writing public SVG and direct PDF. Run `tools/simplebrush-v62/compare.py` and `tools/simplebrush-v62/pdfium.py` on that directory with their pinned dependencies. The 2× route improves these reader errors against generic output; it already admits this input. The PDFium comparison uses an unshifted grid. A clean git archive of commit `5cc39d4cc3e84d99a88da398c1404ec23deb8331` passed the vector assertion and produced byte-identical exports; reader versions and hashes are in the receipt. This control does not establish device or saved-page parity; native transitive dependencies are not fully pinned.

For comparison without recapturing, copy `native.json` to the export directory and decompress `frame.rgba.zlib` into `captures/simplebrush-native-draw-rgba-<native frame SHA-256>.bin` there. The compact JSON contains only fields consumed by the fixture and comparators; it is not the complete capture record.

The receipt retains the original capture hash and a separate hash of the replay script after exclusive output protection. Both comparators enforce the recorded reader versions; temporary render intermediates are isolated from the export directory.
