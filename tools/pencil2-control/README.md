# Pencil2 host control

A fresh setter-built Pencil2 object receives the 87 decoded Fountain source channels with x + 3.25, y - 2.5 and pressure * 0.75. Native ARM64 emulation and host Mesa drew it over the retained synthetic prior, with deferred queue intervention and explicit Update/Draw. The source is not a saved Pencil2 stroke. The frame is 192x192, opaque, with explicit 12-pixel translation and captured grain offset. The Rust replay computes the offset and compares its bits with the native receipt, then compares the entire frame to canvas, PNG, resvg SVG and PDF rendered by MuPDF and PDFium. This is not evidence of saved Pencil2 admission, normal queue scheduling, or device parity.

Run `PYTHONPATH=/tmp/sdocx-marker3-v133-readers .venv/bin/python tools/pencil2-control/compare.py` with resvg and the listed Python reader packages available. The capture script is retained for inspection; recapture depends on the project-local native capture harness and DSO files listed in the original `tools/pencil2-changed-input/receipt.json`, as well as its transitive dependencies. The retained compressed frames make the comparison independent of those native capture dependencies. The second source geometry control has three one-ULP lane differences; this exact raster match does not establish geometry identity generally.

Object metadata with raw flip or rotation-presence flags, unknown property or field bits, or trailing data is rejected. Raw mask checks also reject inconsistent caller-supplied metadata; the captured fresh-object control supplies no object metadata. Source sampling has separate 16,384-point and 16,384-record limits and is not charged to the canvas paint budget.
